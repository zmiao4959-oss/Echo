# Echo 人工验收文档

按步骤手动验证核心链路。预期结果基于最新代码（Phase D + D-Fix）。

---

## 1. 首次启动和 LLM 配置

1. 卸载 App 后重新安装（或清除数据）
2. 启动 App → 应看到 Toast 提示"请先配置 LLM"
3. 自动跳转设置页 → 填写 API Base URL、API Key、Model
4. 点击"保存配置" → 返回主页 → 今日页正常显示

**预期**: 配置后主页不再弹 Toast，天气条/问候语正常显示。

---

## 2. 发起普通对话 → 验证流式输出

1. 在今日页点击"进入对话"卡片
2. 输入"你好，介绍一下你自己"
3. 观察回复

**预期**: 文字逐字流式出现（不是一次性跳出来）。回复内容提到 Echo 的人格设定。

---

## 3. 触发工具调用

1. 在对话中输入"帮我查一下上海的天气"
2. 观察过程

**预期**: 
- 看到"正在执行工具调用..."状态提示
- 看到 `get_weather` 工具被调用
- 返回天气结果
- 如果天气 API 失败，对话能优雅降级（不会崩溃）

---

## 4. 记住用户信息 → 验证记忆可见

1. 对话中输入"记住，我叫小明，我在北京工作"
2. 返回个人中心 → 点击"Echo 记住的事"
3. 查看"用户画像"和"长期记忆片段"

**预期**: 
- 用户画像中显示 Echo 记住的信息
- 长期记忆片段显示 MEMORY.md 中的事实
- 每条记忆可编辑、可删除、可禁用

---

## 5. 查看/编辑/删除记忆

1. 在"Echo 记住的事"页面
2. 尝试编辑一条画像记忆 → 弹出编辑框 → 修改后保存
3. 尝试禁用一个画像 → 开关关闭
4. 尝试置顶一个记忆卡片 → 显示 📌
5. 尝试删除一条长期记忆片段

**预期**: 编辑/删除/禁用/置顶都立即生效，页面刷新。

---

## 6. 新建/切换/删除会话

1. 在对话页点击标题栏（带 ▼ 的标题）
2. 进入对话列表页
3. 点击"新对话" → 进入空白对话页
4. 发送一条消息 → 返回列表页 → 新对话出现
5. 长按某对话 → 重命名 → 确认名称已更新
6. 长按某对话 → 删除 → 确认已从列表消失

**预期**: 
- 删除当前对话后，下次进入今日页会创建新对话
- 对话标题不包含 `[Memory Search Results]` 前缀

---

## 7. 创建提醒 → 验证闹钟触发

1. 对话中输入"提醒我明天早上 9 点开会"
2. 或：在规划页点击 FAB → 创建任务提醒
3. 设置 2 分钟后触发（方便验证）

**预期**: 
- 到时间后收到系统通知
- 通知内容为"⏰ 任务标题"和提醒消息
- 通知点击能打开 App

---

## 8. 重启后恢复会话和提醒

1. 在对话中发几条消息
2. 完全退出 App（从最近任务中划掉）
3. 重新打开 App → 点击"进入对话"

**预期**: 
- 之前的对话历史完整保留
- 提醒闹钟在重启后自动恢复（MyApplication 恢复）

---

## 9. 天气失败诊断

1. 断开设备网络
2. 打开设置页 → 点击"保存配置"返回主页
3. 观察主页天气条
4. 进入设置页 → 查看诊断面板

**预期**: 
- 天气获取失败不崩溃（静默失败）
- 诊断面板中"Weather"显示最近失败次数
- 错误信息不包含 API key

---

## 10. TTS 开关与失败提示

1. 设置页中 TTS 对话语音开关 → 关闭
2. 发起对话 → 不应有 TTS 合成提示
3. 开关 → 打开
4. 再次对话 → 应有 TTS 相关日志

**预期**: 开关即时生效。TTS 未配置时对话不报错。

---

## 11. 主题/背景/纹理切换

1. 个人中心 → 选择主题 → 切换为"森林绿"
2. 返回主页 → 确认主题已切换
3. 个人中心 → 页面纹理 → 选一个纹理
4. 个人中心 → 卡片纹理 → 选一个纹理
5. 个人中心 → 卡片形状 → 选"大圆角"

**预期**: 
- 主题/纹理/形状切换后主页自动刷新
- 卡片圆角变化可见
- 重启后设置保留

---

## 12. 诊断面板检查

1. 打开设置页 → 滚动到底部
2. 查看诊断区域

**预期**: 
- LLM: 已配置（显示模型名）
- TTS: 已配置/未配置
- 天气: 城市名 + 状态
- 通知权限: 已授权/未授权
- 精确闹钟: 已授权/未授权
- 最近错误: 显示各服务的失败摘要

---

## 13. D-Fix: 记忆禁用/待确认生效验证

1. 在"Echo 记住的事"中禁用一条用户画像
2. 发起新对话 → 触发搜索 → 观察系统提示
3. 确认被禁用的画像不出现在对话中

**预期**: 被禁用的画像不注入系统提示，待确认的记忆卡片不出现在主动回忆中。

## 14. D-Fix: 主动陪伴设置生效验证

1. 设置页 → 关闭"开启主动陪伴"
2. 等待一个陪伴计划触发（或手动调整计划时间）
3. 确认不收到陪伴类通知
4. 设置页 → 打开"开启主动陪伴" → 设置静默时段覆盖当前时间
5. 确认静默时段内不收到陪伴通知

**预期**: 陪伴开关和静默时段即时生效。任务提醒不受陪伴开关影响。

## 15. D-Fix: 对话列表搜索验证

1. 进入对话列表页
2. 在搜索框输入关键词
3. 确认列表实时过滤

**预期**: 按标题和消息内容搜索，清空搜索显示全部。
